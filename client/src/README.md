# 插件市场

官方市场提供“全部 / 已安装”筛选。发布成功的插件自动上架，不配置第三方市场源。详情分为介绍、版本与发布、权限；构建状态显示中文，原始日志和版本哈希折叠。启用是主要操作，管理菜单提供停用、回退与卸载确认。

首次加载、空市场、无结果和错误分别展示；刷新保留已有内容、选择和详情滚动位置。

市场只负责列表、选择、安装管理和版本详情的数据交互。左侧按安装状态分组，右侧展示随成功发布版本保存的 README、版本记录和权限。分栏与 Markdown 渲染由共享 UI 组件提供。搜索与选中项保存在当前浏览器会话，移动端使用列表与详情单栏切换。

名称来自发布元数据。父插件尚未发布时使用子插件声明的 `parent_title` 展示父节点，并参与搜索；父插件发布后以其自身标题为准。不将仓库标识作为面向用户的默认名称。

平台发布管理员可在普通插件详情中选择“从市场删除”，确认后调用 `DELETE /api/runtime/marketplace`，请求体为 `{ "git": "插件来源" }`。此操作对所有用户下架条目并禁止新安装，不卸载已安装实例、不删除业务数据和版本历史；后续发布不会自动重新上架。租户卸载仍是独立操作。

插件详情支持按租户隐藏或恢复菜单，隐藏后插件仍运行且保留数据；安装插件后租户成员自动获得插件权限。

已安装并启用的插件可在详情打开其声明的设置页面。设置入口来自当前租户的活动目录，使用宿主统一挂载的 Dialog；市场不读取或保存插件密钥。
