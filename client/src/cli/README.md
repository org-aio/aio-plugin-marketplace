# 本机 CLI 市场

CLI 与宿主插件共用列表。「添加 CLI」弹窗只要求安装命令，Git 地址可选；默认适用系统由浏览器识别，标题备注可在高级选项或保存后编辑。共享 Registration 模型负责默认值和安装方案，网页不解析包管理器也不执行命令。

保存后由页面持久作用域触发 `aio://install`，避免录入弹窗卸载时取消唤起任务。平台发布权限由服务端判定，普通工作区管理员仅查看和安装。README 单独读取与刷新，Markdown 使用源码提交的相对链接和图片基址；读取错误有可见反馈。

宿主安装状态与本机安装记录独立。不将保存或唤起当作安装成功；没有卸载命令时展示手动处理说明。
